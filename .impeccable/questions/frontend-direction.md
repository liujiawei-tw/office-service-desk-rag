# 前端設計方向

原始方向評選選擇了「員工快速指南」。現行實作保留選題、排查、核對來源與轉報修的流程。以下以目前程式碼記錄這些決策在畫面上的呈現方式。

| 設計問題 | 目前實作 |
| --- | --- |
| 員工從哪裡開始？ | 「IT 故障排查與回報中心」預設進入「AI 問答」，也可直接切換至「報修單」。 |
| 如何幫助員工提問？ | 快速索引提供網路與連線、帳號與登入、電腦與周邊、辦公軟體、報修進度五種示例。選取後填入輸入框，員工可編輯再送出。 |
| 回答後可以做什麼？ | 員工可核對來源檔名或繼續提問。一般排查回答也可轉成報修草稿，由員工補齊報修人與類別後送出。 |
| 手機如何切換頁面？ | 760px 以下（含）時，兩個導覽按鈕移至品牌旁的頂部列。對話輸入框保留在對話區下方。 |

目前色彩、字體與斷點詳見設計規格。原始候選稿保留於 mocks 目錄供回顧。[設計規格](../../DESIGN.md) · [候選稿](../mocks/decision/) · [對話實作](../../frontend/src/features/chat/ChatPage.tsx)
